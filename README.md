# Pixel MatriX — Matrix-Based Drawing Tool

## Project Overview
Pixel MatriX is a Python-based desktop application that demonstrates 2D linear algebra through geometric transformations.

## Features
- Translation
- Scaling
- Rotation
- Reflection across the X-axis and Y-axis
- Shear transformations
- Transformation matrix and coordinate display
- Visualization of original and transformed shapes

## Technologies Used
- Python 3
- NumPy
- Matplotlib
- Tkinter

## Installation
Install the required libraries:

```bash
py -m pip install -r requirements.txt
```

## How to Run
Run the desktop application:

```bash
py app.py
```

## Mathematical Concepts
The project uses homogeneous coordinates and 3×3 transformation matrices to transform 2D geometric shapes.
